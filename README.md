# 프로젝트 소개

- **프로젝트 명** : POLINK
- **프로젝트 설명** : AI 기반 경찰 업무 및 분실물 통합 관리 시스템

## 1. 주제 선정 배경

사건 신고, 수사 관리, 분실물·습득물 관리 등 경찰 업무는 다양한 정보를 체계적으로 관리하는 것이 중요하다.

이에 시민의 정보 접근성을 높이고 경찰관의 업무 효율성을 개선하기 위해, 주요 관리 기능을 통합하고 AI 기반 분석 기능을 제공하는 시스템을 기획하였다.

## 2. 기획 의도 및 개발 목표

시민과 경찰관이 필요한 정보를 효율적으로 관리하고 활용할 수 있는 **AI 기반 통합 관리 시스템 구축**을 목표로 한다.

- 사건, 수사, 분실물·습득물 정보의 통합 관리
- 시민의 사건 신고 및 분실물 검색 편의성 향상
- 경찰관의 수사 자료 관리 및 업무 효율화
- AI를 활용한 유사 사례 탐색, 수사 가설 생성 및 분실물 매칭 지원

## 3. 프로젝트 주요 내용

| **구분** | **주요 기능** |
| --- | --- |
| 회원 관리 | 시민·경찰관·관리자별 로그인 및 접근 권한 관리 |
| 사건 관리 | 사건 접수·조회, 담당 경찰관 배정, 상태 및 종결 관리 |
| AI 시민 지원 | 시민이 입력한 상황을 분석하여 유사 범죄 사례 및 대응 방법 안내 |
| 수사 관리 | 증거물, 목격자 진술, 수사 기록 관리 |
| AI 수사 지원 | 사건 자료 기반 수사 가설 및 판단 근거 생성, 담당 경찰관의 채택·기각 |
| 분실물·습득물 관리 | 분실물·습득물 등록, 목록·상세 조회, 검색 및 상태 관리 |
| 반환 관리 | 습득물 반환 신청, 경찰관의 승인·반려 및 반환 완료 처리 |
| AI 분실물 매칭 | 물품의 특징·종류·장소·일시를 분석하여 유사 습득물 추천 |

## 4. 시스템 구성 및 구조

웹 기반 클라이언트-서버 구조로 개발하며, 시민·경찰관·관리자별 접근 권한을 구분한다.

- **Frontend:** 사용자 화면 및 API 연동
- **Backend:** Spring Boot 기반 REST API 및 비즈니스 로직 처리
- **Database:** MySQL 기반 회원·사건·수사·분실물 데이터 관리
- **AI 서비스:** 외부 AI API를 활용한 분석 및 추천 기능

시스템은 회원·사건 관리, 수사 관리, 분실물·습득물 관리의 3개 핵심 도메인으로 구성한다.

## 5. 개발환경 및 기술 스택

본 프로젝트는 Java 및 Spring Boot를 기반으로 REST API 서버를 개발하고, MySQL을 활용하여 데이터를 관리한다.

| 구분 | 기술 및 도구 |
| --- | --- |
| 개발 언어 | Java |
| 백엔드 | Spring Boot, Spring Data JPA |
| 데이터베이스 | MySQL |
| DB 설계 | ERDCloud |
| API 테스트 | Postman (예정) |
| 협업 및 형상 관리 | Git, GitHub (예정) |
| AI 연동 | 외부 AI API (선정 예정) |
| 프론트엔드 | 추후 확정 |

**개발 인원 및 기간**

- **개발 인원:** 3명
- **개발 기간:** 10일
- **개발 방식:** 도메인별 역할 분담 및 병렬 개발

## 6. 활용 방안 및 기대 효과

- **시민 편의성 향상:** 사건 처리 현황 조회 및 분실물 탐색·반환 절차 간소화
- **경찰 업무 효율화:** 사건별 수사 자료의 체계적인 관리 및 정보 접근성 향상
- **AI 기반 업무 지원:** 유사 사례 분석과 수사 가설 생성으로 정보 탐색 및 판단 지원
- **데이터 관리 일관성 확보:** 도메인 간 데이터 연계를 통한 통합 관리
- **확장 가능성:** 향후 AI 분석 고도화 및 통계 기능 추가 기반 마련

본 프로젝트는 실제 경찰 업무 시스템을 대체하기보다, **가상 데이터를 활용하여 AI 기반 통합 관리 시스템의 구현 및 활용 가능성을 검증하는 프로토타입**을 목표로 한다.
