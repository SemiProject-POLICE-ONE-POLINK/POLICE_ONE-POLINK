# 🚔 POLINK

> AI 기반 경찰 업무 및 분실물 통합 관리 시스템

POLINK는 시민, 경찰관, 관리자가 사건과 수사 자료, 분실물·습득물 및 반환 신청을 한곳에서 관리할 수 있도록 만든 웹 기반 프로토타입입니다.  
AI 분석 결과는 수사·반환을 자동으로 결정하지 않는 **참고 정보**이며, 최종 판단과 처리는 담당자가 수행합니다.

## 📌 프로젝트 소개

시민은 사건을 신고하고 진행 상태를 확인하거나 분실물·습득물을 등록할 수 있습니다. 경찰관은 담당 사건의 수사 자료를 관리하고, 반환 신청을 검토해 승인·반려·인계 완료 처리합니다. 관리자는 사건 및 사용자 현황을 관리합니다.

또한 AI 기능을 통해 다음을 지원합니다.

- 시민 입력 상황을 바탕으로 유사 사건과 권장 대응 방법 안내
- 수사 자료를 바탕으로 한 가설 후보 및 근거 제시
- 분실물의 물품명·특징·장소·날짜를 활용한 습득물 후보 매칭

## 🚀 실행 방법

### 1. 백엔드 실행

```bash
git clone https://github.com/SemiProject-POLICE-ONE-POLINK/POLICE_ONE-POLINK.git
cd POLICE_ONE-POLINK
./gradlew.bat build
./gradlew.bat bootRun
```

또는 IntelliJ IDEA에서 `SemiprojectPolinkApplication`을 실행합니다.

기본 주소는 `http://localhost:8080`입니다.

### 2. 프론트엔드 실행

```bash
git clone https://github.com/SemiProject-POLICE-ONE-POLINK/frontend.git
cd frontend
npm install
npm run dev
```

기본 주소는 `http://localhost:5173`입니다.

### 3. 로그인 방법

브라우저에서 `http://localhost:5173`에 접속한 뒤, 로그인 화면에서 아이디와 비밀번호를 입력합니다. 회원가입 화면을 이용해 시민 계정을 새로 만들 수도 있습니다.

`02_DUMMY_DATA.sql`을 실행했다면 아래 테스트 계정으로 역할별 기능을 확인할 수 있습니다.

| 역할 | 아이디 | 비밀번호 | 확인 가능한 주요 기능 |
| --- | --- | --- | --- |
| 시민 | `miran` | `miran12!` | 사건 신고, 분실물·습득물 등록, AI 분실물 매칭, 반환 신청 |
| 경찰관 | `golombo` | `police1!` | 수사 자료 관리, 반환 신청 승인·반려·인계 완료, 물품 통계 |
| 관리자 | `admin` | `admin12!` | 사용자·사건 현황 관리, 물품 통계 |

> 위 계정은 더미 데이터 기반의 개발·시연 전용 계정입니다. 실제 서비스용 계정으로 사용하면 안 됩니다.

## 📚 도메인별 상세

### 1. 회원·인증 (`user`)

- 회원가입과 로그인 기능을 제공하며, 비밀번호는 BCrypt 방식으로 보호한다.
- 로그인 성공 후 JWT를 발급해 API 요청을 인증하고, 역할에 따라 첫 화면과 접근 가능한 메뉴를 분리한다.
- 시민은 마이페이지에서 본인의 사건·물품·반환 현황을 확인하고, 경찰관·관리자는 역할별 대시보드를 사용한다.

### 2. 사건·시민 AI 지원 (`casefile`)

- 시민은 사건을 접수하고 자신의 사건 목록과 상세·처리 상태를 확인할 수 있다.
- 관리자는 사건 목록을 확인하고 담당 경찰을 배정하거나 사건 상태를 관리한다.
- 시민 AI 분석 화면은 입력한 상황을 바탕으로 추천 사건 유형, 대응 방법, 유사 사례를 참고 정보로 제공하며, 분석 결과를 사건 접수에 활용할 수 있다.

### 3. 수사 관리·AI 수사 지원 (`investigation`)

- 담당 경찰관은 사건별 수사 보드에서 증거물, 목격자, 진술, 수사 기록을 등록·조회한다.
- AI는 등록된 수사 자료를 바탕으로 가설 후보와 근거를 제시한다.
- 가설은 AI가 자동 확정하지 않으며, 담당 경찰관이 검토 후 채택 또는 기각한다.

### 4. 분실물·습득물 관리 (`item`)

- 시민은 분실물과 습득물을 등록하고, 물품 종류·카테고리·키워드·장소·날짜·상태로 목록을 검색할 수 있다.
- 물품 상세 화면에서는 등록 정보, 상태, 이미지, 반환 진행 정보를 확인할 수 있다.
- 시민은 본인이 등록한 분실물을 수정하고 이미지가 없는 물품에 이미지를 첨부할 수 있다.
- 경찰관은 보관 중인 습득물 정보를 수정하고, 물품 상태를 반환 업무 흐름에 맞춰 확인한다.
- AI 분실물 챗봇은 물품명·특징·장소·날짜를 분석해 보관 중인 습득물 후보를 안내한다.

### 5. 반환 신청 관리 (`return request`)

- 시민은 본인이 등록한 분실물과 보관 중 습득물을 연결해 반환 신청을 작성하고, 자신의 신청 이력을 조회한다.
- 경찰관은 신청된 분실물과 습득물 정보를 비교해 승인 또는 반려 처리한다.
- 승인된 신청은 실제 물품 전달 뒤 인계 완료 처리하며, 관련 물품 상태와 처리 일시가 함께 갱신된다.

### 6. 물품 통계 (`stats`)

- 경찰관과 관리자는 기간별 물품 등록 현황, 유형·상태·카테고리별 통계를 조회한다.
- 데이터가 없을 때도 화면이 오류 없이 빈 상태로 표시되도록 처리한다.

### 7. 역할별 권한

| 역할 | 주요 권한 |
| --- | --- |
| 시민 | 사건 신고·조회, 분실물·습득물 등록 및 조회, AI 매칭, 반환 신청 |
| 경찰관 | 담당 사건 수사, 수사 자료 및 가설 관리, 습득물 관리, 반환 신청 처리, 통계 조회 |
| 관리자 | 사건·사용자 현황 관리, 물품·통계 조회 |

## 🔐 상태 및 권한 규칙

- 역할: `CITIZEN`, `POLICE`, `ADMIN`
- 물품 상태: `LOST`, `STORED`, `HANDOVER_PENDING`, `RETURNED`
- 반환 신청 상태: `PENDING`, `APPROVED`, `REJECTED`, `COMPLETED`
- AI 추천 결과는 참고용이며, 실제 반환 승인·인계 완료·수사 판단은 담당 경찰이 처리합니다.
